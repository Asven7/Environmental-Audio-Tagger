# References and upstream resources

The following sources identify the principal dataset, model methods and software dependencies used in the project. A formatted university bibliography should be completed according to the required citation style; do not invent papers or experimental comparisons.

1. Salamon, J., Jacoby, C., and Bello, J. P. (2014). **A Dataset and Taxonomy for Urban Sound Research.** *Proceedings of ACM Multimedia* (UrbanSound8K). [Dataset project](https://urbansounddataset.weebly.com/urbansound8k.html).
2. PyTorch team. **PyTorch Documentation.** [pytorch.org/docs](https://pytorch.org/docs/stable/index.html). Used for tensor computation, modules, optimization and checkpoints.
3. Torchaudio project. **TorchAudio Documentation.** [pytorch.org/audio](https://docs.pytorch.org/audio/stable/index.html). Used for Log-Mel feature extraction.
4. scikit-learn contributors. **scikit-learn User Guide.** [scikit-learn.org](https://scikit-learn.org/stable/user_guide.html). Used for classification metrics.
5. Gradio project. **Gradio Documentation.** [gradio.app/docs](https://www.gradio.app/docs). Used for the local file/microphone interface.
6. NumPy, SciPy, pandas and SoundFile documentation. Used for numerical processing, resampling, structured manifests and waveform input/output.

The UrbanSound8K dataset and all third-party software retain their original usage, copyright and attribution conditions. The repository's `LICENSE` covers only code distributed under its stated MIT terms.
